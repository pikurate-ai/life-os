# iPhone 13 Pro에서 Life OS 테스트하기

**2026-10-21 인증 구조 변경:** Safari에서 **[Life OS 열기](https://life-os-563cd.firebaseapp.com/)**를 사용하세요. [모바일/웹 리뷰](https://life-os-563cd.firebaseapp.com/review)는 레이아웃 확인용입니다. Google 로그인은 리뷰의 프레임 안에서 진행하지 않고 독립 앱으로 이동합니다. 앱과 Firebase 인증 도우미를 같은 출처로 배포했습니다. 실제 Chromium은 첫 시도에서 네트워크 오류가 있었고 재시도에서 계정 선택→복귀→계정 표시·새로고침 유지·클라우드 동기화를 확인했습니다. **실제 iPhone Safari·홈 화면 앱·PC/iPhone 두 기기 검증은 아직 남아 있습니다.** [인증 수정 근거](AUTH_FIX_2026-10-21.md)를 확인하세요.

이전 일기 입력창 이탈 제보에 대해 폭·날짜 입력·모달 스크롤을 보완했습니다. 공개 Chromium 390px에서 모달 366px·입력 글자 16px·가로 넘침 없음을 확인했습니다. 아이폰에서는 **새 일기 쓰기 → 날짜 선택 → 본문 입력으로 키보드 열기 → 내부 스크롤 → 저장**을 특히 확인해 주세요. 실제 Safari 결과를 모의 화면 검사와 구분합니다. [최신 검증](QA_2026-10-21.md)에 근거를 남겼습니다.

프로젝트 `life-os-563cd`의 서울 Firestore와 UID별 규칙은 앞선 설정에서 배포했습니다. 현재 앱은 클라우드를 연결한 빌드이며, PC와 아이폰의 실제 같은 계정 확인을 아래 순서로 진행합니다. Safari와 홈 화면에서 사용하는 웹 앱(PWA)이므로 App Store 설치나 TestFlight 초대는 필요하지 않습니다.

기존 [GitHub 주소](https://pikurate-ai.github.io/life-os-preview/)는 보존됩니다. 그 주소에만 저장된 기록은 새 주소에 자동으로 나타나지 않습니다. 기존 주소의 해당 공간에서 먼저 JSON 백업한 뒤 새 주소의 로그인 계정으로 가져오세요. 기존 홈 화면 앱·Safari 웹사이트 데이터·원본 기록을 삭제할 필요가 없습니다. **로컬 지속 캐시가 아직 있어 서버에만 기록을 저장하는 요청은 미구현**입니다.

## 1. Safari에서 열고 홈 화면에 추가

1. iPhone에서 **Safari**를 열어 [현재 앱](https://life-os-563cd.firebaseapp.com/)에 접속합니다. 메신저 안의 브라우저로 열렸다면 링크를 Safari로 옮겨 여세요. 먼저 Safari에서 아래 로그인 확인을 진행해도 됩니다.
2. 화면이 정상적으로 나타나면 **공유** 버튼을 누릅니다. Safari 구성에 따라 페이지 메뉴 안에 공유가 있을 수 있습니다.
3. **홈 화면에 추가**를 선택합니다. 메뉴가 안 보이면 공유 목록 아래의 **동작 편집**에서 찾아보세요.
4. **웹 앱으로 열기** 옵션이 보이면 켜고, 이름을 `Life OS`로 정한 뒤 **추가**를 누릅니다.
5. 새 주소의 **Life OS** 아이콘을 눌러 실행합니다. 이전 주소로 만든 아이콘과 구분하세요. 이전 기록은 그대로 보존합니다.

설치 메뉴는 iOS 버전에 따라 조금 다릅니다. [Apple의 홈 화면 추가 안내](https://support.apple.com/ko-kr/guide/iphone/iph42ab2f3a7/ios)를 참고할 수 있습니다.

## 2. Google 로그인과 PC 동기화 확인

1. 독립 Safari 앱 화면에서 **전체 → 설정과 데이터 → Google로 로그인**을 누릅니다. 모바일에서는 같은 창에서 Google 인증으로 이동합니다.
2. 계정을 고른 뒤 돌아오면 **내 계정**에 실제 Google 이름/이메일과 **Google 계정** 표시가 나오는지 확인합니다. 계정 선택 창이 나왔다는 것만으로 로그인 성공으로 보지 않습니다.
3. 로그인 버튼으로 돌아오거나 오류가 표시되면 새 주소인지 확인하고 오류 문구·Safari/홈 화면 여부·iOS 버전을 남깁니다. 브라우저 기록을 지우지 마세요.
4. PC에서도 [같은 앱 주소](https://life-os-563cd.firebaseapp.com/)에 같은 Google 계정으로 로그인합니다. 비어 있다면 계정과 예시/개인 공간을 먼저 확인합니다.
5. 시험용 메모 하나를 저장하고 동기화 상태가 완료된 뒤 다른 기기에서 확인합니다. 수정·삭제가 반영되는지, 새로고침해도 계정이 유지되는지 확인합니다.

프레임의 **Google 로그인 화면 열기**는 독립 앱을 새 창으로 엽니다. 새 창에서 로그인을 마친 뒤 그 창을 계속 사용하세요. 다른 주소의 원래 프레임이 자동으로 로그인되는 흐름이 아닙니다.

## 3. 예시와 실제 기록 구분

- 상단에 **미리보기**가 보이면 가상 예시 데이터입니다. 화면과 기능을 부담 없이 살펴보세요.
- **내 기록 시작하기**는 예시와 분리된 비로그인 개인 공간입니다. Google 계정의 클라우드 공간과도 별개입니다.
- 첫 테스트는 `아이폰 테스트 일기` 같은 시험용 내용으로 진행하세요. 실제 비밀번호나 중요한 원본 자료를 넣을 필요는 없습니다.
- **전체 → 설정과 데이터**에서 실제 계정과 저장 상태를 확인하세요. 예시·비로그인 개인 공간·Google 계정 공간은 자동으로 합쳐지지 않습니다. 기존 기록을 옮기려면 백업 후 로그인한 계정에서 명시적으로 가져옵니다.

## 4. 5분 사용 확인

홈 화면 앱에서 아래 항목을 순서대로 확인하세요. 하단 **전체** 메뉴에서 나머지 공간을 열 수 있습니다.

- [ ] **일기:** 오늘 날짜로 제목·본문·기분·감사를 입력하고 저장합니다. 다시 열어 수정한 내용이 유지되는지 확인합니다.
- [ ] **건강 → 운동 기록:** 달리기를 선택해 날짜, 거리 `1.2km`, 시간 `10분`을 시험 입력합니다. 목록에 같은 날짜와 수치가 표시되는지 확인합니다.
- [ ] **소중한 순간 → 순간 담기:** 시험용 사진 한 장과 제목·날짜를 저장하고, 사진을 눌러 확대해 봅니다. JPEG·PNG·WebP를 지원하며 HEIC가 거부되면 PNG 스크린샷으로 테스트하세요. 저장되는 것은 압축 사본이므로 원본은 기존 앨범에 보관합니다.
- [ ] **나중에 읽기 → 링크 저장:** 알고 있는 HTTPS 주소와 제목을 저장합니다. 링크 열기, 읽음 표시, 즐겨찾기가 동작하는지 확인합니다.
- [ ] **입력과 화면:** 긴 한글 제목을 넣고 키보드를 띄운 상태에서 모달을 스크롤합니다. 저장·취소 버튼과 하단 메뉴가 겹치지 않고 누를 수 있는지 확인합니다.
- [ ] **다시 실행:** 앱을 닫았다가 같은 홈 화면 아이콘으로 다시 엽니다. 일기·달리기·사진·링크가 그대로 있는지 확인합니다. Safari로 테스트했다면 새로고침 후에도 확인합니다.
- [ ] **백업:** **설정과 데이터 → 전체 기록 백업 → 내보내기**를 눌러 JSON 파일을 파일 앱 등에 보관합니다. 시험용 백업을 다시 **가져오기**하고, 확인 후 같은 기록이 불필요하게 중복되지 않는지 확인합니다.

Safari 화면과 설치한 홈 화면 앱 사이에 저장 공간이 공유되는지는 실기기에서 별도로 확인해야 합니다. 공간이나 계정이 달라 기록이 안 보이면 기존 기록을 지우지 말고, 먼저 해당 공간에서 백업하세요. 백업에는 일반 기록의 원문이 포함됩니다.

## 5. 저장 방식과 검증 이력

현재는 로컬 지속 저장이 성공한 기록을 Firestore로 전송하고 원격 승인을 받은 뒤 동기화 완료로 표시합니다. 오프라인 변경은 기기 대기열에 남습니다. 사용자가 요청한 서버 전용 저장으로 전환한 상태가 아니며, 로그아웃만으로 기존 캐시가 삭제되지 않습니다.

최신 인증 변경의 포맷·타입·일반 테스트 73개·추가 검사·일반 및 Firebase Hosting 빌드는 통과했습니다. Chromium에서는 Firebase 앱에서 만든 합성 메모 1개가 별도 GitHub 출처의 390×844 프레임에 나타나고, 수정한 내용이 Firebase 앱에 반영되는 것을 확인했습니다. 이는 같은 브라우저의 두 출처 검증이며 실제 iPhone Safari·홈 화면 설치·두 기기 결과가 아닙니다. 과거 기기 저장 전용 빌드 `078ebcc`/`d0db06e`의 59개 테스트·규칙 9개·모바일 화면 확인은 [기존 QA 이력](QA_2026-10-21.md)에 보존되어 있습니다.

### 설정에서 확인할 안내

현재 앱의 **내 계정**에는 인증된 계정이 표시되어야 합니다. **저장과 동기화**에서 대기·오류·완료 상태를 구분하세요. 앱의 **미리보기** 표시는 가상 예시 데이터라는 뜻이며 Google 로그인 성공을 뜻하지 않습니다.

문제가 있으면 iPhone의 iOS 버전, Safari/홈 화면 앱 중 어느 쪽인지, 화면의 공간·저장 상태, 재현 순서를 남겨 주세요. 화면 캡처에 개인 기록이나 계정 정보가 보이면 가린 뒤 공유하세요.
