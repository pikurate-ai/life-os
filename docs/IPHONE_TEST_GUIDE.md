# iPhone 13 Pro에서 Life OS 테스트하기

**[Life OS 테스트 버전 열기](https://pikurate-ai.github.io/life-os-preview/)** — 2026-10-21 모바일 입력·백업 개선본으로 갱신했습니다. 소스 `078ebcc`, 정적 `d0db06e`의 배포 성공과 실제 HTTPS 접속을 확인했습니다. 기존 Life OS 서비스와 별도의 테스트 사이트이며, 기존 master 서비스는 변경하지 않았습니다.

이전 일기 입력창 이탈 제보에 대해 폭·날짜 입력·모달 스크롤을 보완했습니다. 공개 Chromium 390px에서 모달 366px·입력 글자 16px·가로 넘침 없음을 확인했습니다. 아이폰에서는 **새 일기 쓰기 → 날짜 선택 → 본문 입력으로 키보드 열기 → 내부 스크롤 → 저장**을 특히 확인해 주세요. 실제 Safari 결과를 모의 화면 검사와 구분합니다. [최신 검증](QA_2026-10-21.md)에 근거를 남겼습니다.

이번 테스트 버전은 **클라우드 연결을 끈 상태**입니다. 예시 화면과 이 기기의 기록·백업 기능을 확인하며, Google 로그인이나 PC와 iPhone의 자동 동기화는 이번 시험 범위에 포함되지 않습니다. Safari와 홈 화면에서 사용하는 웹 앱(PWA)이므로 App Store 설치나 TestFlight 초대는 필요하지 않습니다.

설정 안내를 반영한 일반·iPhone 빌드와 자동 검사를 통과했습니다. 공개 사이트의 HTML·설치 파일 응답, Chromium 390×844 화면의 달리기 저장·새로고침 유지·가로 넘침과 콘솔도 확인했습니다. 실제 iPhone 13 Pro의 Safari·홈 화면 설치 검증은 아래 절차로 진행하세요. 세부 근거는 [QA 기록](QA.md)을 참고하세요.

## 1. Safari에서 열고 홈 화면에 추가

1. iPhone에서 **Safari**를 열어 [테스트 사이트](https://pikurate-ai.github.io/life-os-preview/)에 접속합니다. 메신저 안의 브라우저로 열렸다면 링크를 Safari로 옮겨 여세요.
2. 화면이 정상적으로 나타나면 **공유** 버튼을 누릅니다. Safari 구성에 따라 페이지 메뉴 안에 공유가 있을 수 있습니다.
3. **홈 화면에 추가**를 선택합니다. 메뉴가 안 보이면 공유 목록 아래의 **동작 편집**에서 찾아보세요.
4. **웹 앱으로 열기** 옵션이 보이면 켜고, 이름을 `Life OS 테스트`로 정한 뒤 **추가**를 누릅니다.
5. 홈 화면의 **Life OS 테스트** 아이콘을 눌러 실행합니다. 개인 기록 테스트는 이 화면에서 시작하세요.

설치 메뉴는 iOS 버전에 따라 조금 다릅니다. [Apple의 홈 화면 추가 안내](https://support.apple.com/ko-kr/guide/iphone/iph42ab2f3a7/ios)를 참고할 수 있습니다.

## 2. 먼저 예시로 둘러보기

- 상단에 **미리보기**가 보이면 가상 예시 데이터입니다. 화면과 기능을 부담 없이 살펴보세요.
- **iPhone 테스트 버전 · 기록은 이 기기에 저장돼요 · 클라우드 연결 없음**이라는 안내는 테스트 환경 표시입니다. 가상 예시 데이터 여부를 나타내는 **미리보기** 표시와 구분합니다.
- **내 기록 시작하기**를 누르면 예시와 분리된 빈 개인 공간으로 전환합니다. 이 테스트 버전에서는 해당 기기의 브라우저 저장소에 기록합니다.
- 첫 테스트는 `아이폰 테스트 일기` 같은 시험용 내용으로 진행하세요. 실제 비밀번호나 중요한 원본 자료를 넣을 필요는 없습니다.
- **전체 → 설정과 데이터**에서 **로컬 모드**, **이 기기에 저장** 같은 상태를 확인하세요. 예시와 개인 기록 공간은 분리되어 있으며 자동으로 합쳐지지 않습니다. 이번 테스트 버전에서는 Google 로그인 버튼을 표시하지 않습니다.

## 3. 5분 사용 확인

홈 화면 앱에서 아래 항목을 순서대로 확인하세요. 하단 **전체** 메뉴에서 나머지 공간을 열 수 있습니다.

- [ ] **일기:** 오늘 날짜로 제목·본문·기분·감사를 입력하고 저장합니다. 다시 열어 수정한 내용이 유지되는지 확인합니다.
- [ ] **건강 → 운동 기록:** 달리기를 선택해 날짜, 거리 `1.2km`, 시간 `10분`을 시험 입력합니다. 목록에 같은 날짜와 수치가 표시되는지 확인합니다.
- [ ] **소중한 순간 → 순간 담기:** 시험용 사진 한 장과 제목·날짜를 저장하고, 사진을 눌러 확대해 봅니다. JPEG·PNG·WebP를 지원하며 HEIC가 거부되면 PNG 스크린샷으로 테스트하세요. 저장되는 것은 압축 사본이므로 원본은 기존 앨범에 보관합니다.
- [ ] **나중에 읽기 → 링크 저장:** 알고 있는 HTTPS 주소와 제목을 저장합니다. 링크 열기, 읽음 표시, 즐겨찾기가 동작하는지 확인합니다.
- [ ] **입력과 화면:** 긴 한글 제목을 넣고 키보드를 띄운 상태에서 모달을 스크롤합니다. 저장·취소 버튼과 하단 메뉴가 겹치지 않고 누를 수 있는지 확인합니다.
- [ ] **다시 실행:** 앱을 닫았다가 같은 홈 화면 아이콘으로 다시 엽니다. 일기·달리기·사진·링크가 그대로 있는지 확인합니다. Safari로 테스트했다면 새로고침 후에도 확인합니다.
- [ ] **백업:** **설정과 데이터 → 전체 기록 백업 → 내보내기**를 눌러 JSON 파일을 파일 앱 등에 보관합니다. 시험용 백업을 다시 **가져오기**하고, 확인 후 같은 기록이 불필요하게 중복되지 않는지 확인합니다.

Safari 화면과 설치한 홈 화면 앱 사이에 저장 공간이 공유되는지는 실기기에서 별도로 확인해야 합니다. 공간이나 계정이 달라 기록이 안 보이면 기존 기록을 지우지 말고, 먼저 해당 공간에서 백업하세요. 백업에는 일반 기록의 원문이 포함됩니다.

## 4. 이번에는 기기 내 기록만 확인

PC에서도 테스트 사이트를 열 수 있지만, **PC와 iPhone의 기록은 자동으로 동기화되지 않습니다.** 이번에는 각각의 기기에서 작성·수정·다시 실행·백업을 확인하세요. 이 안내는 iPhone 13 Pro 실기기 검증 완료 보고가 아닙니다.

Firebase의 실제 Google 로그인·허용 도메인·Firestore 규칙을 설정한 이후에만 계정 간 격리와 두 기기 동기화를 따로 시험합니다. 그때 같은 계정으로 로그인해 생성 → 다른 기기 확인 → 수정 → 삭제 반영까지 검증해야 합니다. 기존 로컬 기록을 계정으로 옮길 때도 자동 이동 대신 명시적인 백업·가져오기를 사용합니다.

### 설정에서 확인할 안내

**내 계정**에는 **“테스트 기록은 현재 기기에 보관됩니다.”**라고 표시합니다. **저장과 동기화**에서는 이 테스트 버전이 PC와 아이폰 간 자동 동기화를 제공하지 않으며, 다른 기기로 옮길 때 백업 파일을 사용하라고 안내합니다. Google 로그인 버튼은 숨겨져 있습니다. 앱의 **미리보기** 표시는 별도로 가상 예시 데이터라는 뜻입니다.

문제가 있으면 iPhone의 iOS 버전, Safari/홈 화면 앱 중 어느 쪽인지, 화면의 공간·저장 상태, 재현 순서를 남겨 주세요. 화면 캡처에 개인 기록이나 계정 정보가 보이면 가린 뒤 공유하세요.
