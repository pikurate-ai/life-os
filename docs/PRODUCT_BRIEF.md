# Life OS 제품 기획 v2

## 목적

삶을 주도적이고 긍정적으로 살아가기 위해 일상의 중요한 것을 기록하고 필요할 때 다시 꺼내보는 개인 운영체제. 일·학습·가족·건강·돈·기억을 연결하되, 모두 잘해야 한다는 압박을 더하지 않습니다.

## 사용 맥락

사용자는 AI 관련 업무와 클라우드 학습, 자격 취득, 장기적인 해외 취업 준비를 병행하는 두 자녀의 아버지입니다. 수영·턱걸이·달리기를 일상적으로 기록하고, 가계와 자산을 다시 정리하며, 가족과 개인의 의미 있는 순간을 보관하고자 합니다.

자세한 법적·가족 식별 정보는 제품의 예시 데이터나 공개 문서에 추가하지 않습니다. 모든 일정·금액·건강 수치는 사용자가 직접 기록한 값만 실제 데이터로 취급합니다.

## 재설계 결정

- 오늘 화면을 실제 첫 진입 화면으로 복원했습니다.
- 강제 반복 일기 알람은 제거하고 자발적인 짧은 회고를 권합니다.
- 스트릭을 직접 수정하는 대신 실제 날짜별 완료 기록으로 상태를 계산합니다.
- 이메일 입력을 로그인으로 취급하지 않고 Google 인증 UID를 사용합니다.
- 큰 단일 사용자 문서 대신 사용자별·기록별 문서로 저장합니다.
- 실제 연결되지 않는 Apple Health 표시는 제거합니다.
- Google Docs는 내보낸 TXT/Markdown/JSON 파일부터 가져옵니다. 직접 OAuth 문서 읽기는 별도 후속 기능입니다.
- Chrome·LastPass·Excel에서 내보낸 CSV를 사용자 확인 후 금고로 가져옵니다.
- 예시 데이터와 실제 기록을 철저히 분리합니다. 이전 데이터는 명시적인 가져오기만 허용합니다.

## 상용 출시를 위한 후속 작업

이번 구현은 기능이 동작하는 v2 기반입니다. 실제 운영 환경의 인증·보안 규칙·동기화 검증, 원본 사진 Object Storage, 동의·보관 정책, 계정 삭제와 서버 데이터 삭제, 접근성 감사, 네이티브 앱 배포, 구독 결제는 출시 판단에 따라 별도 완료해야 합니다. 구현·검증되지 않은 기능을 완료로 표기하지 않습니다.

공유 기기에서는 로그인·로그아웃만으로 브라우저의 이전 저장본이 지워지지 않는다는 점을 고려해야 합니다. 민감한 일반 기록 전체의 종단간 암호화는 현재 범위에 포함되지 않으며 암호금고만 별도 암호화합니다.
