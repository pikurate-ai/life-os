# Life OS v2 검증 기록

**최신 결과는 [2026-10-20–21 검증](QA_2026-10-21.md)을 우선합니다.** 포맷·타입·59개 일반 테스트·9개 규칙 통합·일반 빌드가 통과했고 사진/목표/빠른 기록/백업·320px/짧은 화면을 추가 확인했습니다. 아래 2026-10-18의 포맷/규칙 연결/사진 중단 상태는 당시의 이력입니다. 실제 iPhone·앱 OAuth·두 기기 동기화와 실제 사람 10명 평가는 완료하지 않았습니다.

검증 기간: 2026-10-16–18. Windows / Node.js 24 / Chromium 기반 Codex 브라우저에서 검사했습니다. 실제 사용자 데이터 대신 분리된 미리보기 공간과 합성 파일을 사용했습니다. 아래 기록은 **버전과 날짜별 범위**이며 현재 작업본의 모든 검사가 통과한 것으로 읽으면 안 됩니다.

## 자동 검사

당시 자동 검사: 설정 화면의 테스트 안내 보완을 포함한 포맷·타입 검사, 모델·이전·검색 개인정보 보호·편집 메타데이터·테스트 빌드 계약 관련 테스트 **49개**, 별도의 CSV·일기·Web Crypto·다중 금고 검사와 일반 빌드·iPhone 테스트 빌드가 통과했습니다.

최종 독립 검토에서는 계정 변경 시 모든 입력 초안·모달을 폐기하도록 보완하고, 가져온 체중 부가 수치·일기 출처·거래 메타데이터가 편집 후에도 유지되도록 수정했습니다. 잘못된 종류별 필드는 백업·캐시·원격 기록 경계에서 거부하며 관련 회귀 검사를 포함합니다.

- TypeScript strict 검사 통과.
- 결정적 병합, 삭제 tombstone, 계정별 저장 키 격리, 지속 큐, 오래된 탭의 승인 재생성, 시계 역행, 악성 미래 시각, 백업 구조·용량, 금고 평문 차단, 구버전 ID 안정성 검사 통과.
- CSV BOM·인용·줄바꿈·세미콜론·비밀번호 공백, 일기 날짜 분리·중복·잘못된 날짜 검사 통과.
- AES-GCM 왕복, 잘못된 키·변조 거부, 고유 IV, 보안 난수 비밀번호 생성 및 다중 금고 선택·격리 검사 통과.
- 일반 정적 export와 `GITHUB_PAGES=true`의 `/life-os` 정적 export 빌드 통과.

재현 명령:

```sh
npm run typecheck
npm test
npm run build
# PowerShell에서 Pages 경로 검사
$env:GITHUB_PAGES='true'
npm run build
npm run preview
```

개발 서버와 빌드는 같은 Next 출력 디렉터리를 사용하므로 동시에 실행하지 않습니다.

## iPhone 테스트 빌드의 추가 로컬 검증 — 2026-10-17

`npm run build:iphone`이 성공했습니다. 산출물 manifest의 `id`·`start_url`·`scope`·아이콘 경로가 `/life-os-preview/`와 일치하며, 절대 에셋 경로 18개도 해당 경로를 사용함을 확인했습니다. 이것은 로컬 산출물 검사이며 공개 HTTPS 주소의 응답 검사가 아닙니다.

| 로컬 Chromium 390×844 검사 | 확인한 결과                     |
| -------------------------- | ------------------------------- |
| 달리기 기록                | 1.2km / 10분 → 8′20″/km 표시    |
| 긴 한글·영문 메모          | 작성·표시 확인                  |
| 새로고침                   | 저장한 기록 유지                |
| 모달과 입력                | 모달 너비 366px, 입력 글자 16px |
| 가로 레이아웃              | 가로 넘침 0px                   |

이 빌드의 Firebase 연결은 강제로 비활성화되어 있으며 기기 저장과 백업을 시험하는 버전입니다. 설정 화면은 기기 내 저장·자동 동기화 없음을 안내하도록 보완했고 Google 로그인 버튼은 테스트 모드에서 숨깁니다. 해당 변경을 포함한 최종 iPhone 테스트 빌드도 성공했습니다. 실제 iPhone 13 Pro의 Safari·홈 화면 설치와 PC·iPhone 동기화 검증은 별도입니다.

추가로 320px 화면의 전체 메뉴에서도 가로 넘침 0px를 확인했습니다.

## 검증의 범위

별도 창 검사는 같은 브라우저의 로컬 동기화 검사입니다. 실제 데스크톱과 iPhone 사이의 Firebase 동기화를 확인한 것으로 간주하지 않습니다. 실제 OAuth 로그인, Firebase 운영 규칙 배포·에뮬레이터 권한 테스트, iOS Safari/Android 실기기, 네이티브 앱 서명·스토어 심사, 상업 서비스의 개인정보·결제·계정 삭제는 별도 운영 검증이 필요합니다.

현재 버전은 일반 기록을 브라우저 저장소에 보관하며, 암호금고만 별도 종단간 암호화합니다. 사진은 압축 사본과 용량 제한을 사용합니다. 자세한 운영 전제는 [배포 문서](DEPLOYMENT.md)에 있습니다.
