# Life OS 디자인 시스템 v2

이 문서는 다음 개발자와 AI가 동일한 제품 경험을 유지하기 위한 구현 기준입니다. 실제 토큰은 `src/app/globals.css`, 공통 컴포넌트는 `src/components/life-os/ui.tsx`입니다.

## 제품의 인상

차분하고 개인적이며 오래 쓰기 좋은 기록 공간. 오늘의 실행, 의미 있는 회고, 쉽게 다시 찾기를 중심으로 구성합니다. 강압적인 반복 알람, 수치를 조작하는 스트릭 편집, 연결되지 않은 외부 서비스의 성공 표시는 사용하지 않습니다.

Things의 오늘 중심 작업 흐름, Day One의 날짜별 일기와 가져오기 흐름을 참고했습니다. 기존 앱의 브랜드·에셋·화면을 복제하지 않고 Life OS의 독립적인 시각 언어와 정보 구조를 사용합니다.

- Things 공식 가이드: https://culturedcode.com/things/support/articles/4001304/
- Day One 공식 가져오기 가이드: https://dayoneapp.com/guides/settings/importing-data-to-day-one/

## 화면 구조

- 데스크톱: 고정 사이드바 + 헤더 + 최대 폭이 제한된 콘텐츠.
- 오늘: 날짜 → 응원 문구 → 핵심 지표 → 오늘 할 일/루틴 → 일기/주간 운동/목표/읽을거리.
- 모바일: 고정 하단 5개 메뉴. 전체 메뉴에서 모든 영역에 접근.
- 사진은 건강 영역에서 분리. 운동의 기본 순서는 수영·달리기·턱걸이이며 근력 운동도 지원.
- 설정은 계정, 실제 저장 상태, 백업, 가져오기, 설치 안내를 담당.

## 레이아웃 계약

1. Grid는 `minmax(0, 1fr)`, flex의 본문은 `min-width:0`을 기본으로 합니다.
2. 액션은 줄바꿈 가능한 별도 컨테이너에 둡니다. 버튼은 `inline-flex`, `flex-shrink:0`, `white-space:nowrap`.
3. 긴 제목·이메일·주소·URL에는 `overflow-wrap:anywhere`를 적용합니다. 줄임표는 원문을 확인할 별도 화면이 있을 때만 사용합니다.
4. 날짜 입력은 최대 폭 100%, 최소 폭 0, 모바일 폼에서는 한 열로 배치합니다.
5. 하단 메뉴 높이와 iOS safe area만큼 콘텐츠 여백을 확보합니다.
6. 모달은 `100dvh` 기준 최대 높이, 내부 세로 스크롤, 배경 스크롤 잠금. Escape/Tab 순환/닫힌 뒤 포커스 복귀를 지원합니다.
7. 모바일 주요·아이콘 버튼은 44px 이상을 기준으로 합니다. 아이콘 버튼에는 접근 가능한 이름이 필요합니다.
8. 네이티브 확대를 막지 않습니다. `prefers-reduced-motion`을 존중합니다.
9. 320/390/768/1024/1440px 및 긴 한글·영문 제목을 검증합니다. 기기별 완전한 무결점은 검증 없이 선언하지 않습니다.

## 공통 컴포넌트

`Button`, `IconButton`, `Modal`, `Field`, `Badge`, `SectionHeader`, `EmptyState`, `Progress`를 재사용합니다. 동일 동작에 새 스타일의 버튼을 임의로 추가하지 않습니다. 파괴적 동작은 `danger`와 확인 절차를 사용합니다. 입력 오류는 모달을 닫지 않고 초안을 보존합니다.

### 2026-10-18 모달·입력 보완

`Modal`의 `dirty`와 `ModalCloseButton`으로 X·취소·Escape·배경 클릭을 같은 닫기 흐름에 연결합니다. 변경된 초안은 같은 dialog 안에서 계속 작성/버리기를 확인하고 원래 폼은 유지합니다. 브라우저 종료까지 자동 저장하는 기능은 아닙니다.

모바일에서는 모달 자체에 초기 포커스를 두고, VisualViewport 크기/offset을 가용 폭·높이에 반영합니다. 날짜·시간·월 입력은 최소 폭 0/최대 폭 100%와 WebKit 내부 폭을 함께 제한합니다. 매우 긴 모달 제목은 높이를 제한하고 폼 본문은 세로 스크롤합니다. 중첩 drawer/모달은 공유 `lockScroll`을 사용해 마지막 소유자가 닫힐 때 배경 스크롤을 복구합니다. 포커스는 연결된 열기 요소 또는 안전한 대체 요소로 돌아갑니다.

`/review`는 내부 390×844/1440×900을 유지하고 바깥 배율만 줄입니다. 가로/짧은 높이 모의는 레이아웃 확인용이며 실제 iOS 키보드·날짜 선택기 에뮬레이션이 아닙니다. 최신 변경은 Chromium 일부 검증 상태이며 실제 iPhone Safari 확인은 남아 있습니다.

## 데이터에 관한 UX

- 미리보기는 항상 예시 데이터임을 표시합니다. 실제 계정·기기 기록과 저장 영역을 분리합니다.
- ‘저장됨’은 로컬 저장 성공 후, ‘동기화 완료’는 클라우드 확인 후에 표시합니다.
- Google 직접 일기 가져오기와 Apple Health 연결이 구현되지 않았다면 연결 버튼이나 성공 문구를 만들지 않습니다.
- 금고의 마스터 비밀번호는 기록하거나 복구 가능하다고 약속하지 않습니다.
- 사진은 압축 사본임을 명시합니다. 원본 앨범 대체를 약속하지 않습니다.
- 재정·건강은 개인 기록 도구이며 자동 진단, 투자 판단, 법적 절차 안내를 생성하지 않습니다.

## 아이콘

브랜드는 그린 바탕의 8방향 별/꽃 형태로 ‘삶의 여러 영역이 중심에서 만남’을 표현합니다. SVG 원본과 PNG 설치 아이콘은 `scripts/generate-icons.cjs`에서 함께 생성합니다. 기능 아이콘은 기존 Lucide 라이브러리를 사용합니다.
